# 场景提示词规范

本文件的规范优先于正文第四节与第六节的场景示例；两者冲突时以本文件为准。

## 一、六层结构（顺序不可乱）

| 层 | 名称 | 写什么 | 常见错误 |
|----|------|--------|----------|
| 1 | 空间骨架 | 空间类型、结构、进深、开口（门/窗）位置 | 写成剧情描述 |
| 2 | 固定陈设 | 家具、器物、墙面装饰、地面材质 | 把「蒙尘」写这层（应属第 4 层） |
| 3 | 光源灯光 | 白日／夜景 + 色温光质（**默认不写光源在哪**，见第四节） | 与第 4 层氛围重复；**写得太暗** |
| 4 | 氛围世界观 | 空气感、灰尘、情绪基调、时间状态 | 写成心理描写 |
| 5 | 构图与画幅 | 机位、景别、画幅、**顶面可见 + 下三分之一留空** | 忘记两个构图锚点；外景硬写「天花」 |
| 6 | 画质风格锚点 | 通用首锚点 + 尾锚点 | 自创锚点句 |

正文按层标注书写，层名照写：

```
第1层｜空间骨架：……
第2层｜固定陈设：……
第3层｜光源灯光：……
第4层｜氛围世界观：……
第5层｜构图与画幅：……
第6层｜画质风格锚点：……
```

## 二、通用锚点句（逐字复用，但**先按画风选套**）

锚点句决定了这张图**看起来是什么**：真人那套里写着 `ARRI Alexa 实拍质感 … 写实真人，非三维渲染`。3D 动漫 / 动画项目照抄这一套，出来就是**真人照片**——实测发生过，整批场景返工。

**所以第一步是选套，第二步才是逐字复用。** 三套都只有首锚点和尾锚点不同，第 1–5 层的写法完全一样。场景提示词只输出正向内容，不生成负面提示词段。

### 套 A · 真人（项目画风 = 真人）

**开头**
```
真人实拍电影剧照，16:9 横屏构图。
```

**结尾**
```
ARRI Alexa 实拍质感，电影级调色，8K 超高清细节，写实真人，非插画、非三维渲染。画面中无人。
```

### 套 B · 3D 动漫（项目画风 = 3D动漫）

**开头**
```
三维动画电影剧照，16:9 横屏构图。
```

**结尾**
```
三维动画渲染质感，体积光与柔和阴影，材质层次清晰，8K 超高清细节，非实拍、非真人摄影、非二维手绘。画面中无人。
```

### 套 C · 动画（项目画风 = 动画）

**开头**
```
二维动画电影剧照，赛璐璐上色，16:9 横屏构图。
```

**结尾**
```
二维动画赛璐璐质感，线条清晰，色彩明快，分层光影，8K 超高清，非实拍、非真人摄影、非三维写实渲染。画面中无人。
```

### 套 D · 其他（项目画风 = 其他）

把套 A 里的画风描述词换成用户自己那句（例如"水墨动画"），**其余结构不动**，只保留正向画风锚点。

### 选完套之后

- **画幅以 16:9 为准，只换首锚点，其余逐字不动。** 客户要 9:16 竖屏场景底板时，把首锚点整体换成同一套的竖屏版本（`…，9:16 竖屏构图。`）——**不要重写第 1–4 层**。
- 下面第三节起的所有示例都是**套 A（真人）**的写法，只当结构参考；换成 B/C 套时，示例里的锚点句要整句替换。

第 5 层的「顶面锚点 + 下三分之一留空」在 16:9 下同样必写：顶面锚点防顶天，`画面下三分之一留空` 既留出人物站位与走位，也同时充当**竖屏二次裁切的中央安全区**（主体保持在画面中部横向带内，后续裁成 9:16 不会切到主体）。

## 三、第 5 层的顶面锚点要按内外景分写

两个构图锚点（防顶天、防下三分之一被家具占满）**全场景都要写**，但「顶面」的写法要看空间性质：

| 空间 | 顶面锚点写法 |
|------|-------------|
| 室内（房间、走廊、大厅、温室、轿厢、车厢） | `画面上方可见天花`（可加限定，如「低矮的」「高高的」「与吊灯」） |
| 室外（后院、森林、跑道、建筑外景、门前空地） | `画面上方留出<树冠／夜空／建筑顶部／开阔天空>（外景无封闭顶面）` |

- 外景**不能**写「画面上方可见天花」——没有天花，写了会逼模型给露天场景加顶棚。
- 轿厢、车厢这类**有顶但天花板很低**的密闭空间，仍归室内，写「低矮的轿厢天花／车厢天花」。
- 统一自查：每个场景的第 5 层里，`顶面锚点` 与 `画面下三分之一留空` 必须同时出现。

## 四、第 3 层光源写法：两种模式（默认模式 A）

### 模式 A · 不写光源在哪（默认，一律用这个）

固定句式：
```
光源灯光：<白日／夜景>，<色温光质>。整体明亮均匀，不强调单一光源的位置与方向；<让哪些材质与结构清晰可辨>；全画面无暗角、无死黑。
```

正文里**不应出现** `斜射／投出／自上而下／透入／折射／光池` 这类位置型措辞，也不要写灯具的数量与形制。

**为什么**：AI 出图天生偏暗，指定单一光源会直接导致整体压暗。

### 模式 B · 需要氛围时（两层光）

仅当客户明确要电影感时使用：主光 + 环境补光两层，且**仍不许出现大面积全黑**。

## 五、硬规则

- **场景图不写人物。** 空间里永远没人。
- **第 2 层必须覆盖剧情实际动作涉及的家具。** 数字要过一遍剧本的动作行——「打开衣柜」「一屁股坐在椅子上」「掀开被子」这类句子对应的家具（衣柜、访客椅、被褥…）**不能省也不能在精简时删掉**。
- **第 2 层陈设控制在 4–6 项**（「一主一辅一背景」），超 10 项模型会平均分配注意力并自行补出不存在的物件。
- **空间尺度必须给绝对数值，禁用相对参照。** 写「约三米进深」而不是「比一般客厅大」。相对参照模型无法换算，会给出随机的空间比例。
- **昼夜要就地标注。** 每条场景标题下方标出「夜戏场次 ｜ 日戏场次 ｜ 当前第 3 层昼夜 ｜ 是否需补夜版」。夜戏多于日戏时主动提出「夜版应为主资产」。

## 六、多版本（变体）规则

**变体只替换某一层，其余逐字复用。** 不要整段重写，否则已确认的部分会漂移。

| 变体类型 | 改哪层 | 原因 |
|----------|--------|------|
| 日夜切换 | 只改**第 3 层** | 日夜的本质是光源变化 |
| 时间状态（蒙尘 / 清洁） | **第 3 层 + 第 4 层** | 蒙尘属第 4 层空气感，同时影响光线散射；若写进第 2 层，清洁版会改不动 |
| 机位／景别变化（全景 ↔ 近景） | **第 2 层 + 第 5 层** | 主体范围与构图同时变 |
| 空间改造（加封条、拆门等） | **第 2 层** | 属固定陈设变化 |

夜版一律**只改第 3 层**，不另立资产。所有变体都必须从同一场景的原图走图片编辑（`task=image-edit`）；夜版、反打、雨天和改造前后都不得用文生图重新生成，否则空间、门窗和陈设会漂移。

## 七、场景命名

按「地点-序号 + 视角/状态」命名，例如：

- `湖屋-1 外景`
- `湖屋-1-附玄关`
- `湖屋-2 客厅`

同一地点的主体场景与附属空间用 `-附` 标记。

```

第1层｜空间骨架：一栋美式湖畔小屋的正面外景，单层木构建筑，外墙上部可见倾斜的木瓦屋顶边缘与檐下阴影，建筑位于画面中轴，正前方是一条通往湖岸的碎石小径；画面左右两侧可见深色林地的树干与低矮灌木，背景为灰绿色湖面与远山。
```

## 十、反打图（用户给参考图，要同一空间的对面视角）

- 提示词开头必须写明「以所附参考图为同一空间，生成该场景的反打视角」。
- **第 3／4 层原样搬，第 1／2／5 层按新机位重写。**
- 结尾必须加正向「一致性要求」段：材质／配色／工艺／灯光与同一空间完全一致，仅机位反向 180°，门窗位置和数量沿用原场景。
- **最大风险是反打会拍到原图未覆盖的那面墙**——先从条目第 1／2 层推导，推导不出来就先补进原条目再写。

## 十一、改单条场景后的三个自查

1. 第 5 层里 `顶面锚点` 与 `画面下三分之一留空` 是否同时出现？
2. 第 3 层是否还残留位置型措辞（`斜射／投出／自上而下／透入`）或灯具形制？
3. 第 2 层陈设是否在 4–6 项内，且剧情实际动作涉及的家具没有缺？
