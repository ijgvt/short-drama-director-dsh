# 道具／资产生图提示词规范

本文件的规范优先于正文第五节与第六节的道具示例；两者冲突时以本文件为准。

## 一、正文骨架

正文**直接从这一句开始，不带任何头部字段**（不写【道具】/ 类型 / 风格 / 画幅 / 背景 / 生成图片名称）：

```
纯白底道具单视角展示：<视角>。道具：<轮廓 → 颜色 → 材质 → 结构件 → 新旧程度 → 使用痕迹 → 与手部比例>。真实材质与光影，主体四周留足白边，比例符合现实。画面只呈现这一件道具，表面干净，道具本身不带文字。
```

字段顺序与含义：

| 字段 | 写什么 | 示例 |
|------|--------|------|
| 轮廓 | 外形、尺寸感、形状特征 | 圆形、窄圈、方盒、长条 |
| 颜色 | 主色 + 辅色，用材质色不用形容词 | 哑光黑表壳、玫瑰金表圈 |
| 材质 | 真实材料名 | 抛光白金、拉丝不锈钢、羊皮纸 |
| 结构件 | 可辨认的部件 | 表冠、搭扣、抽屉式内托、封条、卡扣 |
| 新旧程度 | 全新 / 九成新 / 明显旧化 | 边缘轻微磕碰、表面细密划痕 |
| 使用痕迹 | 与剧情一致的使用感 | 内页有折角、封面有指痕 |
| 与手部比例 | 参照物，避免比例失真 | 约一枚硬币大 / 单手可握 |

风格：`{画风}` 的材质与表面质感（画风取项目设置）｜ 默认纯白底 ｜ 实物道具 1:1。
**不写死"真人写实"**：3D 动漫 / 动画项目照抄真人那句，出的就是一张照片；真人项目强调真实材质、划痕与反光，3D 项目强调三维材质与体积光影。道具骨架句本身（第 1 段）不随画风变，只替换风格限定。道具提示词只输出正向内容，不生成负面提示词段。

## 二、视角分档（按物体形态选，别一律用一种）

| 形态 | 视角 | 说明 | 正向画面约束 |
|------|------|------|----------------|
| **立体实物**（戒指、腕表、饰品、器物、包袋、钥匙、盒子） | **45 度斜侧立 / 三分之四侧视**，单视角 | 让立体轮廓、侧面结构与厚度同时可见；保持真实厚度，不压成扁平面 | 一个完整主体，真实厚度与立体轮廓清晰 |
| **空间 / 陈设**（轿厢、花房、书架、床、陈列柜） | 同上 **45 度斜侧视**；立面型（门、窗、面板）改**正视** | 空间保持真实进深与结构，画面中只有目标陈设 | 单一空间主体，真实进深，画面中无人 |
| **电子设备**（手机、平板、电脑、终端、对讲机） | **三视图**：正面 / 侧面 / 背面，三格并排 | 屏幕保持**熄屏全黑**；机身保持无品牌标识的通用外观。仅剧情必须显示屏幕内容时才改单视角亮屏（此时文字逐字指定） | 三格属于同一台设备，镜头布局按专节写死 |
| **平面物件**（文件、报告、照片、卡片、档案、表单） | **正背面并排**：左侧正面（有文字），右侧同一件翻转后的背面（纯白/纯色、无文字） | 画幅 16:9。屏幕界面没有「背面」，不适用此档 | 两页属于同一件，正背面颜色与材质一致 |
| **服装 / 穿戴类**（制服、礼服、护甲、战斗服） | **正面 + 背面并排**，平铺展示，不出现人体 | 画幅 16:9。结尾必加 `两态为同一套 X，材质配色完全一致。` | 两态属于同一套，材质配色一致 |
| **虚拟道具 / 特效概念图**（契约纽带、能力光效、气场、仪式流程、密谋计划） | 深色底，**单一主视角** | 不写 `纯白底`、不写 `道具：`，改用 `概念：`。画面以概念主体为主；需要人物时只给剪影/背影 | 单一主视角，以概念主体为画面核心 |

**视角需要其他角度时**：只改「展示视角」那一句单独重跑，**不合并进同一张图**。

### 电子设备专节（手机最常见，翻车点固定）

- 屏幕**熄屏全黑**是默认。只有剧情必须看到屏幕内容时才改单视角亮屏，并把文字逐字写死。
- **摄像头模组必须写死几何，不能给混合描述。** 最常见的翻车点是「**方形/矩形模组里竖排三枚镜头**」——方形岛与竖排镜头是两套互斥的排布逻辑，模型一定会画出畸形模组。
- **默认排布：近正方形圆角模组 + 三枚镜头三角排布**（左上、左下两枚上下对齐，第三枚居右中），闪光灯与拾音孔放模组内右下角。**镜头默认不要竖着排。**
- 也**不要**退回「药丸形竖向模组 + 竖排镜头」的写法。客户另有指定（如横向一排三枚）按其指定写死，不要自行混合。
- 必写项：模组边长占机身宽度的比例（如「约为机身宽度的四成」）、模组与背板之间的凹槽分界、模组以外**背板无任何其他开孔**。
- 镜头数量、方向、间距和排布必须逐项写死；每枚镜头完整、互不遮挡，闪光灯与拾音孔各出现一次。
- 机身保持通用无品牌外观，屏幕保持熄屏纯黑；仅剧情要求亮屏时，逐字指定界面内容。

## 三、功能性多态默认合并成一张

同一道具的「闭合 / 打开」「正面 / 背面」等状态，**优先放在同一条指令里左右并排**，不要拆成多条。

```
纯白底道具并排展示：左侧为<状态A>，右侧为<状态B>，两态并排，画面 16:9。道具：<同一件的共同描述：材质、配色、结构>。两态为同一件道具，材质配色完全一致。……
```

- 画幅用 16:9。
- 正文明确写出“两态属于同一件道具，材质、配色与结构完全一致”。

## 四、文件类道具的内容厚度

人事档案、病历、事故报告、尸检报告、婚礼策划文件等「看着像真文件」的道具，**字段要写够**：

- 机构抬头 / 徽标位（可写死字母，或留空白位）
- 档案编号（格式固定，如 `M-2024-0417`）
- 主体字段：姓名、出生日期、科室 / 部门、日期
- 表格线与栏目名
- 签名栏、盖章位
- 页脚编号与页码

内容单薄会一眼假。例外：婚礼策划画册这类**给顾客看的参考册**，不必显示内文，做一个精美封面即可。

## 五、多件套道具：「能不能放进去」是尺寸属性，不是构图

客户说「拖把要能放在桶里」「箱子要装得下」时，**要的是尺寸关系成立**，不是要你把它画成装进去的样子。这两件事必须分开写：

| 诉求 | 写在哪里 | 怎么写 |
|---|---|---|
| **能不能放进去** | 道具描述里的**尺寸对比** | `拖把头直径约十八厘米、桶口内径约二十厘米，因此这把拖把可以整支放入桶中` |
| **图上画成什么样** | **展示视角那一句** | `水桶与拖把左右并排、各自独立完整呈现、两件之间留出适中间距、互不遮挡` |

**别用构图去表达功能关系。** 把拖把画成插在桶里，看似「证明了能放进去」，实际是：① 两件物体交叠、出图容易糊成一块；② 后期没法单独抠出桶或拖把；③ 客户真正要的功能信息（尺寸匹配）反而被构图吃掉了。

多件套的标准画法：同一视角下**各自独立完整呈现、互不遮挡**（并排或错落排布），每件都完整可见。

写成并排后，正文要明确“两件各自独立完整、互不遮挡，尺寸关系符合描述，画面中不画成装入状态”。

## 六、命名

`prop_reference_<项目序号>_<道具名>`

同一项目所有道具共用同一序号，序号按项目登记。

## 七、增补与维护

- 追加新道具时**只追加**，不改动已确认条目。
- 同一道具若已存在，先查有无重复，能合并则合并（如同一份报告同时用于两集，只出一条，备注复用集数）。
- 分集追加的屏幕／纸质素材，统一归到道具总文件末尾的 `三、分集追加素材` 章节，按 EP 编号分小节。
