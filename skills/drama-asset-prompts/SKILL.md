# 资产生成提示词（step_1）

本技能的权威提示词就是同目录下的 `PROMPT.md`——**它是唯一依据，必须逐条照做**。开始前用文件工具完整读一遍 `PROMPT.md`，然后按它执行。

**变体来源硬规则：** 本技能写的服装、年龄、受伤、场景日夜、反打、道具状态等变体提示词，全部是**图片编辑指令**，不是新的文生图提示词。每条变体必须写明以哪一张原资产/原变体作为 `<image1>`；没有原资产时不能靠文字生成“差不多”的新资产。文生图只用于第一次出现的原资产。

**场景与道具有独立规范，写这两类之前必须先把对应的参考文件也读一遍：**

- `references/场景提示词规范.md` —— 场景六层结构、通用首尾锚点句（逐字复用）、第 3 层光源两种模式、第 5 层内外景顶面锚点、变体分层规则、完整示例。**与 `PROMPT.md` 冲突时以参考文件为准。**
- `references/道具提示词规范.md` —— 道具正文骨架、视角六档分档规则（立体实物／空间陈设／电子设备／平面物件／服装穿戴／虚拟特效）、功能性多态合并、电子设备摄像头模组写法、多件套尺寸与构图分离。**与 `PROMPT.md` 冲突时以参考文件为准。**

人物规范不做替换，仍以 `PROMPT.md` 第三节为准。

输入是**两个文件**：

1. 剧本文件（`<输入1：剧本文件>`）——所有外观与年代/文化设定的唯一依据。
2. 上一步 `drama-asset-inventory` 产出的**《资产盘点稿》**（`<输入2：资产盘点稿>`）——资产名与资产清单的唯一依据，名字一律取盘点稿里的原样写法。

配套动作：

- **画风必须取当前项目的设置，不许自己定成真人写实。** 开工前读一次项目设置（`storyboard action=settings project=<项目>`，或 `.director/project.json` 的 `settings.artStyle` / `styleSentence`），按四选一映射成画风描述：

  | 项目设置 | 提示词里写的画风 |
  |---|---|
  | 真人 | 电影级写实画面，注重光影氛围与细节，质感逼真 |
  | 3D动漫 | 三维动画风格，注重体积感与材质表现，光影柔和，角色造型圆润 |
  | 动画 | 二维动画风格，赛璐璐上色，线条清晰，色彩明快，注重作画张力 |
  | 其他 | 用户自己写的那句话（原样保留关键词） |

  **项目还没定画风时，先问一次四选一，不要默认。** 素材必须和最终视频同一种画风，否则资产图和成片接不起来。
- 输出顺序固定为 **人物 → 场景 → 道具**。
- 画幅：人物 = 9:16 竖构图纯白底单人全身照；群演群像 = 16:9；**场景 = 16:9 横构图**（固定不变，用户明确要竖屏底板时才换首锚点句）；道具 = 1:1（功能性多态并排时 16:9）。
- 每个人物只写一条 9:16 基础全身照提示词（这是唯一需要完整写人物长相的图，也是文生图唯一允许的人物基础资产）；服装变体各写一条以基础全身照为 `<image1>` 的图片编辑提示词，并写明"只换服装/鞋/配饰，脸、五官、瞳色、肤色、发型、发色、体型与基础全身照完全一致"。不得先写一条文生图服装参考图来充当变体来源。
- 固定写入项不可省略（人物专用）：`{画风}，短剧影视剧质感，电影级光影，符合该画风的材质与细节，高清 8K，超细节，锐利对焦，无畸形五官，无扭曲手部，无水印，无文字，商业可用，避免和真人明星撞脸。画风锁：严格保持用户指定画风（见上一条的项目画风映射表），禁止画风漂移。`
- 场景与道具**不用**上面这条人物固定写入项：场景用参考文件里的画风首锚点与尾锚点；道具用参考文件里的道具骨架句。**任何资产都只生成正向提示词，不生成“负面提示词 / 反向屏蔽词”段。**
- **那三句锚点句是按画风成套的，必须挑与项目画风同一套。** 真人那套写的是 `ARRI Alexa 实拍质感 … 非三维渲染`，照抄到 3D 动漫 / 动画项目上，出来就是**真人照片**（实测：3D 动画项目的场景图出了实拍感，整批返工）。参考文件里的示例是**真人示例**，只学结构，别连锚点句一起抄。
- 资产名一律用盘点稿里的原样写法。**如果盘点稿里某个场景/道具/群演的名字带括号，先按 `drama-asset-inventory` 的规则改掉再写提示词**（括号只属于人物变体），并在交付里说明改了哪一个——不改，后面引用就会抓到别人的图。
- 每条提示词写成**一整段连续文本**，可直接复制，不带元信息行、不带文件后缀、不带 `@`。基础资产提示词交给文生图；变体提示词交给图片编辑，并保留 `<image1>` 等参考图编号。道具正文不带任何头部字段。
- 最后附上 `PROMPT.md` 第八节的自检表（人物 6 条、场景 5 条、道具 4 条、通用 2 条）。
- 生图指令只写视觉外观，**不得写入声音、音色、台词、性格情绪动作**。

交付：写成 Markdown 文件（建议 `<工作区>/资产/资产提示词/资产提示词.md`）。用户对某张图不满意时，直接按用户要求改对应那条提示词再重新生成，不要让用户自己去改文件。
