1. 通读“输入1”剧本与“输入2”资产盘点稿，提取全部人物、场景、道具，并确认其年代、国家、文化、日/夜、内/外景、材质、文字内容与使用方式。

4. 最后输出统一自检表。

三、人物资产生成规范

【3.1 基础角色：只出一张 9:16 全身照】
每个人物只生成一张基础形象图（9:16 白底全身照），它同时是该角色后续所有图片（换装、年龄/状态变体）的唯一外观依据。不再输出半身照、面部特写与三视图。

- 资产名：角色名（即《资产盘点稿》中的人物资产名，不加任何前缀或编号）。
- 画幅：9:16 竖构图，纯白背景。
- 构图：单人正面全身像，人物居中，头顶与脚底各留出余量；全身完整入画，头发、手指、脚与鞋、衣摆都不得截断。
- 站姿：自然站立，双手自然下垂于身体两侧，双腿自然并拢或与肩同宽，身体正对镜头，头部端正，不低头、不仰头、不歪头、不侧身。
- 表情：中性平静，视线水平直视镜头，禁止笑、皱眉、哭泣、愤怒、惊讶等表情。
- 必须穿衣服：完整呈现整套服装，包括颜色、材质、版型、领口、袖长、衣长、裤长或裙长、鞋与配饰；禁止裸露、内衣、泳装、无上衣、衣物缺失、透视到露肤。
- 发型：完整露出额头与脸部，头发不得遮住眼睛、眉毛或主要脸型；女性角色尽量避免偏分发型，优先中分或对称可镜像发型。

【3.2 服装变体（不同服装）：9:16 图片编辑提示词】
同一人物需要不同服装时，每套服装各输出一条 9:16 图片编辑提示词，以 3.1 基础全身照作为 `<image1>`，通过图片编辑工作流生成 9:16 白底全身服装展示图；基础形象图保持不变，服装图不替代基础形象图。**禁止先用文生图生成服装参考图或新人物图，再把那张图登记为变体。**

- 资产名：角色名（服装名）（即《资产盘点稿》中该服装变体的资产名，如 男主（西装），不加前缀）。
- 画幅：9:16 竖构图，纯白背景。
- 参考图：必须上传该角色 3.1 的 9:16 基础全身照作为 `<image1>`，并在提示词里写明“严格以 9:16 基础全身照为唯一人物外观依据（资产名：角色名），不重新描述人物长相”。用户另外提供已确认的服装参考图时，只能作为 `<image2>` 的服装辅助，不得取代人物原图。
- 画面：单人正面全身像，自然站立，双手自然下垂于身体两侧，中性表情，正对镜头，视线水平直视镜头；构图、景别、站姿与基础全身照完全一致，方便对比与剪辑。

- 同角色只有一套服装时跳过本节，只保留 3.1 的基础全身照。

【3.3 年龄/状态变体】

四、场景资产生成规范

**权威规范见 `references/场景提示词规范.md`，必须完整读一遍再写场景，本节只是提要；冲突时以参考文件为准。**

场景按**六层结构**书写，顺序不可乱，层名照写：`第1层｜空间骨架` → `第2层｜固定陈设` → `第3层｜光源灯光` → `第4层｜氛围世界观` → `第5层｜构图与画幅` → `第6层｜画质风格锚点`。第 6 层结束后直接结束，不追加负面提示词段。

- 资产名：场景名（即《资产盘点稿》中的场景资产名，不加前缀）。
- 画幅：**16:9 横构图**（本片场景底板固定 16:9，不要擅自改成 9:16）。仅当用户明确要竖屏场景底板时才把首锚点换成**同一套画风**的竖屏版本（如 `…，9:16 竖屏构图。`），**第 1–4 层一字不动**。
- 通用首尾锚点句**逐字复用**，但**先按项目画风选套**（三套的完整写法在 `references/场景提示词规范.md` 第二节）：

  | 项目画风 | 开头 | 结尾 |
  |---|---|---|
  | 真人 | `真人实拍电影剧照，16:9 横屏构图。` | `ARRI Alexa 实拍质感，电影级调色，8K 超高清细节，写实真人，非插画、非三维渲染。画面中无人。` |
  | 3D动漫 | `三维动画电影剧照，16:9 横屏构图。` | `三维动画渲染质感，体积光与柔和阴影，材质层次清晰，8K 超高清细节，非实拍、非真人摄影、非二维手绘。画面中无人。` |
  | 动画 | `二维动画电影剧照，赛璐璐上色，16:9 横屏构图。` | `二维动画赛璐璐质感，线条清晰，色彩明快，分层光影，8K 超高清，非实拍、非真人摄影、非三维写实渲染。画面中无人。` |
  | 其他 | 同结构，画风词用项目设置里那句 | 同左 |

  **首尾锚点必须整套匹配画风。** 照抄真人套，3D 动漫 / 动画项目就会出真人照片——实测发生过，整批场景返工。本节下面的示例是**真人**示例，只当结构参考。
- **场景图不写人物。** 空间里永远没人。
- **第 3 层默认不写光源在哪**（模式 A）。固定句式：`光源灯光：<白日／夜景>，<色温光质>。整体明亮均匀，不强调单一光源的位置与方向；<让哪些材质与结构清晰可辨>；全画面无暗角、无死黑。` 正文里不得出现 `斜射／投出／自上而下／透入／折射／光池` 这类位置型措辞，也不写灯具数量与形制。AI 出图天生偏暗，指定单一光源会直接导致整体压暗；只有客户明确要电影感时才切模式 B（主光 + 环境补光两层），且仍不许大面积全黑。
- **第 5 层必写两个构图锚点**：顶面锚点 + `画面下三分之一留空`。顶面锚点分内外景——室内写 `画面上方可见天花`（轿厢/车厢写「低矮的轿厢天花」）；**室外写 `画面上方留出<树冠／夜空／建筑顶部／开阔天空>（外景无封闭顶面）`**，外景写「天花」会逼模型给露天场景加顶棚。`画面下三分之一留空` 既留人物站位与走位，也充当竖屏二次裁切的中央安全区。
- **第 2 层陈设控制在 4–6 项**（一主一辅一背景），超 10 项模型会自行补出不存在的物件；同时必须覆盖剧本动作行实际涉及的家具（「打开衣柜」「坐在椅子上」对应的衣柜、椅子不能省）。
- **空间尺度给绝对数值**（`约三米进深`），禁用相对参照（`比一般客厅大`）。
- 提取信息：内景/外景、日/夜、具体国家与年代、天气、光线氛围、建筑/家具风格、空间关系、人物会从哪里进出、主要互动区在哪。
- 空间预演：保证人物有足够走位与调度空间；门、楼梯、走廊等出入口必须完整可见，前景不得被无关家具遮挡。
- 背景差异：同一画面左、中、右背景不要完全一样，便于后续固定人物站位。
- 场景真实感：必须符合剧本交代的国家、地域与年代，不得引入剧本没有的地域元素；欧美题材禁止混入中式或日式元素。
- 比例真实：场景内任何道具必须符合真实尺寸。
- 昼夜就地标注：每条场景标题下方标出「夜戏场次 ｜ 日戏场次 ｜ 当前第 3 层昼夜 ｜ 是否需补夜版」。夜版只改第 3 层，不另立资产。
- 变体只替换指定层，其余逐字复用：日夜切换只改第 3 层；蒙尘/清洁改第 3+4 层；景别变化改第 2+5 层；空间改造改第 2 层。
- **场景变体来源：** 日版、夜版、反打、雨天和改造前后等已有场景变体，必须从同一场景的原图走 `task=image-edit`，不得用文生图重新生成。夜版以原场景图为 `<image1>`，只改光源、色温、明暗和必要的时间氛围，空间、陈设、门窗和机位关系保持不变。

道具正文**直接从这一句开始，不带任何头部字段**（不写【道具】/ 类型 / 风格 / 画幅 / 背景 / 生成图片名称）：

- 带文字道具：能不给字就不给字；必须给字时**逐字写死**。文件类道具字段要写够（机构抬头、档案编号、姓名/日期、表格线、签名栏、盖章位、页脚页码），内容单薄会一眼假。
- **多件套道具：「能不能放进去」是尺寸属性，不是构图。** 尺寸关系写在道具描述的尺寸对比里（`拖把头直径约十八厘米、桶口内径约二十厘米，因此可以整支放入`），图上画成**各自独立完整呈现、互不遮挡**。别用构图表达功能关系。
- 时代与风格一致：道具的年代、地域与风格必须与剧本设定一致。
- 每个道具提示词在正向描述后直接结束，不追加负面提示词或反向屏蔽词。
