# 资产盘点（step_0）

本技能的权威提示词就是同目录下的 `PROMPT.md`——**它是唯一依据，必须逐条照做**。开始前用文件工具完整读一遍 `PROMPT.md`，然后按它执行。

配套动作：

- 先读用户提供的剧本文件（可以用 `read` 工具直接读）。
- 画风：用户没指定就默认真人写实；用户在提示词【输入2】里填了画风，就以用户指定的为准，并原样写进盘点稿开头，供 `drama-asset-prompts` 沿用。
- 剧本内容不完整时，按剧本交代的时代背景与题材合理补全、直接采用，不要标注"补全"；但不得改变剧情核心、角色关系和结局。
- 输出为 Markdown《资产盘点稿》，按集组织，包含 `PROMPT.md` 里【输出0】到【输出6】的全部小节。
- 资产名规则：直接用角色/场景/道具本身的名称，不加 `character_`/`scene_`/`prop_` 前缀，不加 `_01` 编号。
- **分集资产需求总表是索引，不是声明。** 每一项都必须在本稿后有同名人物/场景/道具的详细条目；只在总表或台词里出现一次的名称，不创建空资产卡。
- 资产条目标题不要加 `1.`、`2.` 序号；即使作者写了序号，资产库和盘点解析也会统一剥掉，真正身份以“××资产名”字段为准。
- “声音与语气 / 配音说明 / 无实体旁白”不是视觉资产，不进入人物资产盘点。
- **括号只给人物变体用，这是唯一的例外**：`男主（军装造型）`、`女主（受伤）` 必须这么写，因为资产库和 `@引用` 都按这个语法认变体。
  **场景、道具、群演的资产名里一律不许有括号。** 括号会被资产库当成"变体"解析：
  `青岚宗弟子（群像）` 会变成「资产 = `青岚宗弟子` + 变体 = `群像`」，于是 `@青岚宗弟子` 绑到的不一定是你要的那张图（实测抓成了纸鹤镇的镇民）。
  群像就写 `青岚宗弟子群像`，或者干脆只立一个 `青岚宗弟子` 当一个群体资产。
- **一个道具一个名字，不用括号区分形态。** 同一件道具的两种形态（`问雪剑` 与它的纸化形态）要么**另起独立名字**（`问雪剑纸化`），要么在映射里明确写清用哪一张。
  写成 `问雪剑（纸化）` 会让它变成 `问雪剑` 的一个变体，引用时报「有未绑定的 H3 参考资产」——因为系统没法替你决定"这一镜用哪个形态"。
- **群演是一个群体资产**：`围观群众`、`记者若干`、`宴会宾客` 各算一个资产，不按画面人数拆成多个人物；场景里只写"若干"，映射里只引用一个群体资产。
- **同一场景的多张图是一个场景资产下的变体**：`旧仓库` 的基础图、夜版、反打都归到场景 `旧仓库`，不要拆成三个场景资产，也不要另立"夜版/日版"这种没有地点名的资产。
  注意区分两件事：**括号写在文件名里**（`旧仓库（夜）.png`）表示"这是 `旧仓库` 的夜版"——这是对的；**括号写在资产名里**（把资产叫 `旧仓库（夜）`）——这是错的。
- 盘点时要把每个变体的来源写成“基于原资产编辑”：场景夜版/反打基于该场景原图，人物服装/年龄/受伤基于该人物原形象，道具状态基于该道具原图。这里的来源是后续图片编辑的硬依赖，不是一句说明；不能把它理解成重新文生图。
- 场景图始终按 **16:9 横构图**准备，与短剧最终画幅（9:16 或 16:9）无关；夜景和反打图也保持 16:9。
- 盘点稿是整个流程的资产清单唯一来源，后面 `drama-asset-prompts` 和 `drama-asset-production` 都以它为准，不得新增、改名、合并或漏掉资产。

交付：把盘点稿写成一个 Markdown 文件（建议 `<工作区>/资产/资产盘点稿/资产盘点稿.md`），并在对话里给用户一段**简短**结论（几个人物、几套变体、几个场景、几个道具、哪些跨集复用），不要把整张表贴进聊天窗口。
